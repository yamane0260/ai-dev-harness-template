## Avoid

- decorative UI with no product purpose;
- repetitive card grids by default;
- meaningless badges/pills/metrics;
- gratuitous gradients/glow/glass effects;
- invented marketing claims, quotes, or statistics;
- styling based only on vague adjectives such as "modern" or "premium".

## Visual verification

For user-facing work, render the actual interface and review screenshots at representative sizes. Source inspection alone is not sufficient visual QA.

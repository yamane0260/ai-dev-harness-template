# Workflow Skills

Skills are maintained workflow instructions shared by supported AI coding tools. They do not replace executable verification.

- Start/adopt: `bootstrap-project`
- Normal implementation: `develop-feature`
- Specification quality: `spec-gap-preflight`
- Deterministic/fresh review: `verify-work`, `review-code`, `review-security`, `review-ux`, `review-design`
- Assurance: `review-assurance`
- Durable knowledge: `explain-change`, `review-legibility`
- On-demand understanding: `explain-system`
- Human decision: `prepare-approval`
- Release: `release-change`
- Diagnosis: `debug-systematically`

Open only the Skill triggered by the current task plus directly referenced policy/evidence. Do not chain every Skill mechanically.
